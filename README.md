# HireTrack - Job Management System

HireTrack is a RESTful backend application for managing job opportunities and user authentication.

## Features

- User registration and login
- JWT-based authentication
- Role-based authorization
- Job CRUD operations
- Search by job title and location
- Pagination and sorting
- Validation and exception handling
- MongoDB integration
- Swagger/OpenAPI documentation

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- JWT
- MongoDB
- Maven
- Swagger/OpenAPI
- Docker
- Postman
- Render

## API Endpoints

### Authentication
- POST /users/register
- POST /users/login

### Jobs
- GET /jobs
- GET /jobs/{id}
- POST /jobs
- PUT /jobs/{id}
- DELETE /jobs/{id}
